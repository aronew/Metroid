# SOL review log

One entry per sheet SOL delivers for a prompt book card: what was checked,
what passed, and the fix sent when it fell short. The checks are the book's
"Check every result" list. Play each sheet in the book's sheet tester at 1×
and ¼× before writing its entry.

## Template

```
### H12 cowl_run (take 1, date)
- Drawings: 12 of 12, no copies
- Flip-through: smooth / jumps at frame N / freezes
- On model: yes / drifts (what)
- Anchor: soles on y = 400 / off by N px in frames …
- Card specifics: (the lean, the arms, the slouch …)
- Verdict: pass / redraw frames … / redo
- Fix sent: (name from "If SOL falls short")
```
